moon-element

用 MoonBit 写的标准 Web Components —— 组件按标准自定义元素注册，可嵌进任意页面或框架。

1 · 属性驱动 + 组件对外派发事件

按钮只是改属性：el.setAttribute("count", n)。组件重渲染后， 通过声明为 crossing（bubbles + composed）的事件通知页面； 非法值不会报错，而是**回退到默认值**。

2 · shadow DOM 样式隔离

页面里的 .pill（被页面样式染成粉色）

页面给 .pill 和 span 定了很霸道的样式，但组件内部的 .pill 完全不受影响 —— shadow DOM 把样式挡住了。

3 · HTML 转义

设成 HTML 后看到的仍然是**字面文本**：组件默认走转义路径，不会把用户输入当标签执行。
