# Generated output for light DOM mode

Generated by the CLI and committed so that CI verifies the light-mode skeleton compiles
and runs as well.

```bash
moon run cmd/main -- x-light-panel --mode light > examples/generated-light-panel/component.mbt
```

Difference from [`../generated-x-counter`](../generated-x-counter): the generated code has
one extra line, `mode=@core.LightDom`. Content is not rendered into a shadow root but into
the element itself, and `core.scope_css` scopes the styles to `x-light-panel`.
